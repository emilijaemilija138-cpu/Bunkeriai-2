# NordState Shelter

Profesionali, mobiliesiems pritaikyta MB „NordState“ modulių, bunkerių, priedangų ir civilinės saugos sprendimų svetainė lietuvių kalba.

## Failai

- index.html – pradžios puslapis, sprendimų kategorijos, paslaugos, procesas, DUK ir užklausos forma.
- styles.css – dizainas ir prisitaikymas prie telefono / planšetės / kompiuterio.
- app.js – mobiliojo meniu valdymas, modelio pasirinkimas, užklausos paruošimas el. paštu ir teksto kopijavimas.
- privacy.html – privatumo politika.
- terms.html – svetainės naudojimo sąlygos.
- favicon.svg – originali svetainės piktograma.

Nereikia npm, framework ar build žingsnio. Atidarykite index.html naršyklėje arba įkelkite į statinių puslapių hostingą.

## GitHub Pages publikavimas

1. Atidarykite GitHub saugyklą → Settings → Pages.
2. Skiltyje Build and deployment pasirinkite Deploy from a branch.
3. Pasirinkite main ir /(root), paspauskite Save.
4. GitHub Pages adresas turėtų būti https://emilijaemilija138-cpu.github.io/Bunkeriai-/ (tik aktyvavus Pages; jei saugykla privati, publikavimas priklauso nuo GitHub plano ir nustatymų).
5. Jei reikia atskiro domeno, prijunkite jį per Pages nustatymus ir DNS. Nenaudokite pagrindinio nordstate.shop domeno neįvertinę poveikio esamai svetainei.

## Užklausos forma (SVARBU)

Ši statinė versija nepriima ir nesiunčia užklausų per serverį. Ji suformuoja laišką naudotojo el. pašto programoje per mailto: ir parodo kopijavimo galimybę, jei el. pašto programa nesukonfigūruota.

Prieš komercinį paleidimą rekomenduojama prijungti saugų užklausų API ar formų tiekėją, įgyvendinti spam apsaugą, serverinį validavimą, pristatymo patvirtinimą ir atitinkamai atnaujinti privatumo politiką. Nenaudokite asmeninio el. pašto API raktų tiesiogiai naršyklės kode.
